# Тиск — застосунок для iPhone (SwiftUI + HealthKit)

Простий застосунок: форма з трьома полями (**SYS / DIA / PUL**), збереження
з поточними датою й часом, локальна історія вимірів і **запис у Apple Health**.

## Що вміє

- Форма з трьома полями: систолічний, діастолічний, пульс.
- Кнопка «Зберегти» → вимір іде **одночасно**:
  - у локальну історію (JSON-файл на пристрої, не зникає між запусками);
  - у **Apple Health** (кров'яний тиск як кореляція SYS+DIA, плюс пульс).
- Історія списком: значення, дата/час, категорія тиску (кольорова крапка),
  позначка ❤️ що вимір записано в Health.
- Свайп ліворуч у списку — видалити запис із локальної історії
  (з Health при цьому не видаляється — це роблять у самому Health).

## Файли

```
Sources/
  BloodPressureLoggerApp.swift   — точка входу, під'єднує сховище й HealthKit
  Reading.swift                  — модель виміру + категоризація тиску
  ReadingStore.swift             — локальна історія (JSON у Application Support)
  HealthKitManager.swift         — дозволи та запис у Apple Health
  ContentView.swift              — форма + список історії
Support/
  BloodPressureLogger.entitlements — вмикає HealthKit
  Info-additions.plist             — 2 обов'язкові ключі-описи дозволів
```

## Як зібрати й поставити на iPhone (потрібен Mac з Xcode)

Збірку я звідси зробити не можу — потрібен Xcode на Mac. Кроки:

1. **Створи новий проєкт** у Xcode:
   `File → New → Project… → iOS → App`.
   - Product Name: `BloodPressureLogger`
   - Interface: **SwiftUI**, Language: **Swift**.
2. **Заміни/додай файли.** У новому проєкті вже є `…App.swift` і
   `ContentView.swift` — видали їх і перетягни в проєкт усі файли з теки
   `Sources/` цього репозиторію (галочка «Copy items if needed»).
3. **Увімкни HealthKit:**
   таргет → вкладка **Signing & Capabilities → + Capability → HealthKit**.
   Xcode сам створить `.entitlements`. (Файл `Support/BloodPressureLogger.entitlements`
   тут — як зразок; можеш узяти згенерований Xcode.)
4. **Додай описи дозволів:** таргет → вкладка **Info** → додай два ключі з
   `Support/Info-additions.plist`:
   - `Privacy - Health Update Usage Description`
   - `Privacy - Health Share Usage Description`
5. **Підпис:** вкладка **Signing & Capabilities** → Team → обери свій Apple ID
   (безкоштовний «Personal Team» підходить). Bundle Identifier зроби
   унікальним, напр. `com.tsesliuk.bloodpressure`.
6. **Під'єднай iPhone** кабелем, обери його як пристрій-ціль, натисни **Run (▶︎)**.
7. На iPhone: `Налаштування → Основні → VPN і керування пристроєм` →
   довір своєму розробницькому профілю (потрібно один раз).
8. При першому запуску застосунок попросить **дозвіл на запис у Health** —
   дозволь для тиску й пульсу.

> ⚠️ Безкоштовний акаунт: підпис діє **7 днів**, потім застосунок треба
> перевстановити з Xcode. З платним Apple Developer ($99/рік) — рік.

## Перевірка, що запис пройшов

Відкрий **Health → Огляд → Серце → Артеріальний тиск** — там з'явиться
твій вимір із датою/часом. Пульс — у розділі **Серце → Пульс**.

## Примітка

Категоризація тиску («Підвищений», «Гіпертензія 1 ст.» тощо) у застосунку —
лише орієнтовна візуальна підказка за загальними порогами ACC/AHA, **не
медична порада**. За тлумаченням показників звертайся до лікаря.
