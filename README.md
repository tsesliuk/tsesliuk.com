# tsesliuk.com

Two static sites in one repo. No build step, no framework — plain HTML/CSS/JS.
Each page is self-contained with its own inline `<style>`.

## What's where

| Path | Serves | Notes |
|------|--------|-------|
| `www/` | **tsesliuk.com** (main portfolio) | apex domain web root |
| `www-oleksii/` | **oleksii.tsesliuk.com** (CV / profile) | subdomain web root |
| `www/works/*.html` | case-study pages | one file per case |
| `www/images/tiles/` | homepage work thumbnails (SVG) | generated by `_gen_thumbs.py` |
| `www/uk/`, `www-oleksii/uk/` | Ukrainian versions | site is bilingual EN + UA |
| `_gen_thumbs.py` | regenerates the tile SVGs | run with `py _gen_thumbs.py` |
| `serve-local.bat` | one-click local preview | double-click it |

## Development

See [SETUP.md](SETUP.md) for Mac/Windows preview and the two-site deployment boundary. Follow [AGENTS.md](AGENTS.md). Existing pages use both older shared styles and newer inline styles; inspect the page being changed. Preserve EN/UA parity, existing design tokens and client confidentiality.

The AgileEngine case uses www/works/agileengine_design_system.html and www/images/ae_ds/. Its older handoff is retired; verify actual HTML/links and asset availability before changing the homepage or claiming publication approval.
