Case study2018 to 2022Halliburton · via LuxoftSenior UX Architect & Lead Designer

Real-time drilling data, redesigned for remote surveillance.

When Covid-19 made remote surveillance business-critical, the DSRT365 web product was not ready for it. Over four years I led UX research, the redesign, and a design system spanning desktop real-time monitoring and InSite Mobile.

Client
Halliburton (Oil & gas)
Years
2018 to 2022
My role
Senior UX Architect & Lead Designer
Products
Real-time monitoring web app, InSite Mobile, design system
The problem

A business-critical tool that did not support how people now worked.

Business problems
  • The web product became business-critical during Covid-19, but the UI and UX did not support remote surveillance
  • The company did not know what to improve to retain and win customers
User problems
  • The screen distracted attention: too many controls
  • Users were unaware of new features and updates after each release
  • The support team had to explain data management over the phone
The solution

Less on screen, more in context.

A UX audit and stakeholder and user interviews defined the direction. We shipped a Full Screen mode that removes controls when engineers monitor live data, integrated chat into the Home screen for in-product communication, and created a tutorials page with shareable feature walkthroughs so releases explain themselves.

A brand style and design system covers the Drilling, Well, Production, Information Management and Investment domains, across desktop and InSite Mobile.
